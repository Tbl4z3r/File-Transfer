# File Transfer

Aplicación personal para transferir archivos entre Windows y Android por la red local, con cifrado y sin cuentas ni servicios externos.

Estado: contrato y compatibilidad aprobados; implementación H1 en curso. El objetivo del primer incremento es una transferencia manual cifrada en ambos sentidos con integridad comprobada. No hay todavía una versión lista para instalar.

Consulta [alcance](docs/project-brief.es.md), [tareas](docs/tasks/BOARD.md) y [continuidad](docs/CONTINUITY.md).

Se usa GitHub Flow: `main` estable y ramas cortas por tarea. El destino autorizado es `Tbl4z3r/File-Transfer`.
